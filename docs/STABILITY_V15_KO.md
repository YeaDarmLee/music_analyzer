# 13트랙 보완 결과 · v13~v15 (v12 대비)

정답이 있는 32개 조건으로 비교했다. SDR은 정답과의 오차 기준이며 높을수록 좋다. 32개 조건은 기존 v12 결과와 캐시된 문맥 추론을 재사용해 새 단계만 적용했고, 기사개전은 v15 전체 파이프라인으로 처음부터 다시 추출했다(427초). 모든 조건에서 원곡·반주 합계와 길이 검증을 통과했다.

## 적용한 단계
| 버전 | 단계 | 내용 |
| --- | --- | --- |
| v13 | `string_routing.py` | 원곡 문맥 근거로 신디·추가 반주·코러스에 흩어진 바이올린을 스트링으로 복귀 |
| v14 | `percussion_refinement.apply_backing` | 코러스로 샌 종·방울류 타악기를 기타 타악기로 복귀 |
| v15 | `context_routing.py` | 기타로 분류된 브라스, 추가 반주·신디로 빠진 일렉기타를 복귀 |

세 단계 모두 해당 주파수에서 원곡 문맥 근거가 더 강하고 위상이 일치할 때만 옮긴다. 근거가 없으면 아무것도 옮기지 않는다(단위 테스트로 확인).

## 하락·부작용
- 스트링: Slakh 가상 악기 -0.02~-0.16dB, 패드 조건 0.52 → 0.00dB(패드 성분이 스트링으로 더 들어감).
- 작은 가상 브라스 -0.67 → -0.71dB, Phoenix 추가 반주 5.49 → 5.46dB.
- 보컬 SDR은 모든 조건에서 하락하지 않았다.
- 기사개전: 기타 트랙 에너지 +1%, 추가 반주 -5%, 신디 -13%로 소폭 이동했다. 정답이 없는 실제 곡이라 정확도 개선인지 판정할 수 없다. 나머지 트랙은 v13과 동일.

## 남은 문제
- **신디 패드:** 지금 모델로는 해결 불가. 보유한 53개 악기 판별 부분을 모두 확인했다. 테스트 패드는 스트링 판별에 82~95%, 바이올린 판별에 66%로 잡히고 신디 판별에는 0%다. 패드/스트링 구분 데이터로 학습하거나 새 모델이 필요하다.
- **작은 가상 브라스:** 원곡 문맥 모델도 거의 인식하지 못해(근거 5% 이하) 문맥 복귀로 해결되지 않는다.
- **작은 말렛:** 모든 악기 판별 부분의 근거가 57% 이하라 신호 자체가 약해 보류했다. 큰 말렛은 96.7%.
- 일부 Slakh 일렉기타는 개선돼도 SDR이 1dB대로 낮다.
- 테스트는 짧은 샘플과 인공 믹스 위주다. 다양한 실제 곡으로 확인한 결과는 아직 없다.
