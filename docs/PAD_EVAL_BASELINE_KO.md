# 신디 패드 평가 세트와 v15 기준선

## 평가 세트 (`scripts/build-pad-eval.py`, 데이터는 `data/pad-eval`, git 제외)
- 15초 조건 72개. 패드 음색 32종: GM Pad 1~8(GeneralUser GS 사운드폰트로 렌더링) 8종, 직접 합성한 패드 24종(톱니·사각·삼각·배음 합성, 유니즌·디튠·필터·엔벨로프·코러스·리버브를 음색마다 다르게 설정).
- 음색 번호가 짝수면 개발용, 홀수면 최종 평가용. 같은 음색을 학습/평가에 나누지 않는 분리 기준이다.
- 조건 구성: 패드+스트링+배경(피아노·베이스·드럼, 일부 기타·브라스) 32개, 같은 조건에서 패드만 -12dB로 줄인 16개, 패드를 뺀 대조군 16개, 패드+스트링+피아노만 8개(파일명은 `pad*-piano`, 스트링 포함).
- 정책(확정): **신스 스트링(GM 50·51)은 신디로 취급한다.** 신스 스트링 정답을 신디로 두었을 때 모델 출력과의 일치가 8.02dB, 스트링으로 두었을 때 0.09dB였다(신스 스트링 음색 8개, 18개 조건 중 13개에서 신디 쪽이 우세). 스트링 대조군은 GM 바이올린·비올라·첼로·트레몰로·스트링 앙상블이다.
- 한계: 모두 합성이다. 같은 사운드폰트의 스트링과 패드를 함께 썼고, 실제 완성곡과 다르다. 합성 패드 24종은 사람이 만든 것이라 실제 패드 분포를 대표하지 않는다.

## v15 기준선, 확정 정책 적용 (실패 0건, 72/72 완료, `docs/PAD_EVAL_V15.json`)
아래 표는 신스 스트링을 신디 정답에 포함한 최종 수치다. 처음 측정(신스 스트링=스트링)과 달라진 이유와 이전 수치는 맨 아래 "대조군 이상 3건의 원인" 절에 있다.
SDR은 높을수록 좋다. 잡힌 신호 비율은 정답 패드 신호 중 신디 트랙에 들어간 비율이다.

| 조건 | 개수 | 신디 SDR 중앙값 | 신디에 잡힌 패드 신호 중앙값 | 스트링 SDR 중앙값 |
| --- | ---: | ---: | ---: | ---: |
| 패드+스트링, 전체 | 32 | 4.85dB (0.16 ~ 15.50) | 51.9% (2.8 ~ 96.6) | 8.50dB (24개) |
| 개발용 | 16 | 3.87dB | 45.0% | 8.07dB |
| 최종 평가용 | 16 | 5.48dB | 59.1% | 8.61dB |
| 작은 패드(-12dB) | 16 | 1.42dB (0.00 ~ 14.54) | 17.3% (0 ~ 100) | 12.20dB (12개) |
| 패드 없는 대조군 | 16 | - | - | 12.78dB (12개) |

스트링 SDR 개수는 신스 스트링 음색 4~8개를 신디 정답에 넣었기 때문에 줄었다.

- 패드가 신디로 잡힌 정도: 10% 미만 2개, 10~50% 14개, 50% 이상 16개, 80% 이상 8개. 신디 SDR이 3dB 이상인 조건은 32개 중 20개, 6dB 이상은 12개.
- 음색 편차가 크다. 가장 잘 잡힌 것은 GM Pad 7(halo) 98.6%, 가장 못 잡힌 것은 GM Pad 5(bowed) 2.8%와 GM Pad 6(metallic) 6.7%. GM 패드 8종 중앙값은 31.1%, 직접 합성 패드는 59.1%다.
- 앞서 Slakh 패드 1개로 본 0.3%는 가장 나쁜 쪽이었고, 음색 전체로 보면 평균 약 절반이 잡힌다. 문제가 모든 패드에서 같은 형태라는 가정은 맞지 않다.
- 작은 패드는 훨씬 나쁘다(17.3%). 패드 있는 조건의 스트링 SDR(8.50dB)이 패드 없는 대조군(12.78dB)보다 낮아 패드가 스트링을 오염시킨다.
- 패드 없는 대조군 16개 중 13개는 신디 출력이 믹스 대비 -48dB 이하로 거의 없다. 나머지 3개는 신스 스트링 반주가 신디로 간 것이다(정책 확정으로 이제 정상 출력으로 본다).

## 대조군 이상 3건의 원인 (확인 완료)
`pad06-nopad`, `pad14-nopad`, `pad07-nopad`의 신디 출력은 **신스 스트링 반주**였다. 정답과의 상관으로 확인했다.

| 조건 | 반주 스트링 | 최종 신디 출력에 들어간 스트링 신호 | 처음 원인이 생긴 단계 |
| --- | --- | ---: | --- |
| pad06-nopad | Synth Strings 1 | 76.8% | 원곡 문맥 모델(mega7)의 synth 출력에 스트링 83.4% |
| pad14-nopad | Synth Strings 1 | 68.4% | 같은 단계에 스트링 92.1% |
| pad07-nopad | Synth Strings 2 | 9.9% | 같은 단계에 스트링 52.1% |

- 모델은 신스 스트링을 신디로 분류한다. 이 평가 세트에서 "신스 스트링은 스트링"이라는 정책을 정했지만 모델의 분류와 반대다. 3건은 모델 오류라기보다 **정책과 모델 정의의 충돌**이다.
- 같은 이유로 신스 스트링을 쓰는 8개 음색(`pad06,07,14,15,22,23,30,31`)은 지표가 왜곡된다. 이 8개를 빼고 다시 계산하면 아래와 같다.

| 조건 | 구분 | 신디에 잡힌 패드 중앙값 | 신디 SDR 중앙값 | 스트링 SDR 중앙값 |
| --- | --- | ---: | ---: | ---: |
| 패드+스트링 | 전체 32 | 51.9% | 2.52dB | 7.57dB |
| | 신스 스트링 제외 24 | 45.0% | 3.87dB | 8.50dB |
| | 신스 스트링만 8 | 79.4% | 0.02dB | 0.24dB |
| 작은 패드 | 신스 스트링 제외 12 | 11.3% | 0.73dB | 12.20dB |
| 패드 없음 | 신스 스트링 제외 12 | - | - | 12.78dB |

- 신스 스트링이 들어가면 신디 SDR 0.02dB, 스트링 SDR 0.24dB로 무너진다. 모델이 신스 스트링과 패드를 같은 신디로 보고 둘이 섞인다.
- 신스 스트링을 뺀 24개 기준으로 패드는 약 45%가 신디로 가고, 패드 없는 대조군에서는 신디 오출력이 없다(-71dB).
- **결정:** 신스 스트링은 신디로 둔다. 모델 출력과의 일치가 더 높은 쪽(8.02dB 대 0.09dB)이며 코드 변경이 필요 없다. 정답을 `synth_strings` 키로 따로 두고 평가에서 신디 정답에 합산한다(`ground_truth.evaluate`). 위 표의 "신스 스트링 제외" 수치(패드 45.0%, 신디 SDR 3.87dB)는 신스 스트링이 없는 24개 기준이다. 신스 스트링이 있는 8개 음색의 신디 SDR 중앙값은 8.42dB, 나머지는 3.87dB다.
