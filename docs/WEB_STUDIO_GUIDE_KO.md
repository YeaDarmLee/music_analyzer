# 웹 스튜디오 사용 가이드

## 실행

환경과 모델이 준비된 이 PC에서 PowerShell로 실행합니다. 프론트 빌드에는 Node.js가 필요합니다.

```powershell
cd C:\workspace\music_analyzer
.\scripts\start-web.ps1
```

브라우저에서 http://127.0.0.1:8780 에 접속하면 메인 화면이 표시됩니다. 상단 로그인 버튼으로 모달을 열어 회원가입 또는 로그인합니다. 본인 분석만 표시됩니다. [회원·MySQL 설정과 DDL](ACCOUNTS_MYSQL_KO.md)을 참고하세요. 이미 빌드했다면 `-SkipBuild` 옵션을 사용할 수 있습니다. 종료는 실행한 터미널에서 Ctrl+C입니다.

## 사용 흐름

1. 홈에서 **새 분석**을 누르고 MP3/WAV/FLAC 파일을 선택합니다. 현재 URL 입력은 지원하지 않습니다.
2. 분석 시작 후 업로드와 모델 처리 진행 상태가 표시됩니다. 다른 분석이 GPU를 사용 중이면 기다립니다.
3. 완료한 항목을 클릭하면 파형이 있는 트랙 스튜디오가 열립니다.
4. 함께 재생하거나 M(음소거), S(솔로), 트랙 음량, 재생 위치를 조절합니다.
5. 각 트랙의 다운로드 버튼으로 WAV를 받거나 전체 ZIP을 받습니다.

## 최종 트랙 구성

**확정한 Mel-Band RoFormer 보컬 1개 + 반주에서 분리한 드럼·베이스·기타·피아노·other 5개**를 한 결과로 제공합니다.

악기 분리 모델이 추가로 추출한 보컬은 최종 재생·개별 다운로드·ZIP에서 제외합니다. 진단용 작업 파일은 그대로 보존합니다. 기존 분석도 원본/반주 해시와 길이로 확정 보컬 작업을 연결합니다. 반주만 따로 입력한 과거 작업에서 원본 보컬을 찾을 수 없다면 악기 5개만 표시합니다.

청취용 파일은 공통 고정 gain을 적용한 PCM16이며, 다운로드는 원래 FLOAT WAV입니다. 화면 음량 조절은 다운로드 파일을 변경하지 않습니다. 분리 품질 자체는 선택한 모델과 곡에 따라 달라집니다.

## 데이터와 실행 범위

서버는 이 PC의 127.0.0.1에만 연결됩니다. 분석 기록·업로드·미리보기·ZIP은 `data/separation/web` 아래, 모델 작업은 기존 `data/separation/jobs` 아래에 저장됩니다. 모두 Git 제외 대상입니다. 서버를 다시 시작하면 기록을 불러오며 중단된 웹 분석은 실패로 표시합니다. 재분석은 새 분석으로 시작합니다.

## 검증

프론트 프로덕션 빌드 성공 및 Python 테스트 130개 통과. 확정 보컬 교체, ZIP 내 보컬 파일 일치, 캐시 분리, 오디오 Range 응답, 경로 제한, 업로드 오류 처리를 검증했습니다.

## 원본 비교와 선명도 개선 방향

상세 화면의 첫 트랙은 원본 음원입니다. 기본 음소거이며 S 버튼으로 원본만 들을 수 있습니다. 원본도 상세 진입 시 미리 로드합니다. 화면 트랙은 원본 + 분리 결과 6개이고 전체 ZIP은 분리 결과만 포함합니다. 원본은 첫 트랙 다운로드 버튼으로 별도 저장합니다.

선명도 개선은 원본과 같은 구간을 비교한 뒤 트랙별로 판단합니다. 우선 200–500Hz의 불필요한 뭉침을 넓은 Q로 1–3dB 줄이고, 필요한 트랙만 2–5kHz 존재감을 1–2dB 높이는 정도부터 시험합니다. 이 수치는 시작점이며 모든 트랙에 일괄 적용하지 않습니다. 베이스 저역과 드럼 몸통을 무조건 깎지 않습니다. 원본 RAW를 보존하고 별도 후처리 결과로 A/B 비교합니다. 빠진 연주·수중음 같은 분리 왜곡은 EQ로 복원되지 않으므로 모델/분리 단계 재검토 대상입니다. 후처리 EQ와 개선본 다운로드 기능은 아직 구현하지 않았습니다.

## 선명도 후처리 사용

상세 화면에서 선명도 후처리 ON/OFF로 분리 원음과 실시간 EQ 결과를 비교합니다. 기본 ON, 각 트랙 강도 50%입니다. 강도 0은 보정 없음이고 100은 기본 보정의 두 배입니다. 원본 REF에는 적용하지 않습니다. 오른쪽 다운로드 버튼은 선명도 ON일 때 원음·개선음·둘 다 선택 창을 엽니다. 개선음은 다운로드 창을 연 시점의 노브 값으로 원래 FLOAT 분리 파일에 EQ를 적용해 생성하고 캐시합니다. 전체 다운로드에도 같은 선택을 제공하며 둘 다 선택하면 raw/clarity 폴더를 가진 ZIP을 받습니다. OFF일 때는 바로 원음을 다운로드합니다. 재생 음량 및 M/S는 파일에 적용하지 않습니다. 선명도 토글은 전체 트랙 다운로드 왼쪽에 있으며 ON일 때만 노브가 표시됩니다. 노브는 위아래 드래그 또는 방향키로 조절합니다. 개선 WAV는 EQ 특성상 0dBFS를 넘는 샘플을 가질 수 있으며 자동 정규화는 하지 않습니다. 기존 결과에도 적용되므로 재분리할 필요가 없습니다.

## 전체 선명도 조절

선명도를 켜면 전체 강도가 100%로 설정됩니다. 토글 옆의 노브 하나로 모든 분리 트랙의 강도를 함께 조절하며 원본 REF에는 적용하지 않습니다. OFF에서는 노브가 숨겨지고 트랙 높이는 항상 동일합니다. 개선 다운로드와 둘 다 받기는 다운로드 창을 연 시점의 전체 강도를 각 트랙에 적용합니다.

## 외부 접속 설정

회원 기능 도입 후 start-web.ps1 기본값은 로컬 전용입니다. 외부 공개는 HTTPS 프록시와 AUTH_COOKIE_SECURE=1 설정을 준비한 뒤 start-web.ps1 -PublicAccess로 명시합니다. Python 직접 실행은 --host 0.0.0.0 --public-access를 사용합니다. 백엔드 HTTP 포트는 프록시에서만 접근하도록 제한하고, 브라우저에서는 HTTPS 주소를 사용합니다. 상세 설정은 [회원 기능 가이드](ACCOUNTS_MYSQL_KO.md)를 참고하세요.
