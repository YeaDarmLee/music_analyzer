# 브라스를 포함한 최종 11트랙

2026-10-07. 사용자가 분홍신 24–60초의 Mega53 브라스·반주 입력을 승인했으며, 입력 선택 확인에서 기본 악기 8개 추출 후 나머지를 계산하는 방식을 선택했다.

표시 순서: 보컬, 코러스, 피아노, 신디사이저, 스트링, 브라스, 어쿠스틱기타, 일렉기타, 베이스, 드럼, 나머지.

## 서비스 흐름

1. 44.1kHz 스테레오 WAV 변환.
2. 원곡 보컬/반주 분리.
3. 동일 반주에서 피아노/베이스/드럼과 Mega5의 신디/스트링/브라스/어쿠스틱/일렉을 추출. 브라스는 공식 Mega53 index 8을 보존한다. 다른 네 헤드는 index 1,16,38,7을 유지한다.
4. 보컬에서 리드/코러스 분리.
5. 반주에서 악기 8개를 빼 나머지 생성.
6. 나머지 신디 보완. 기존 피아노/어쿠스틱/일렉/베이스/드럼 제외 조건 유지.
7. 갱신된 나머지 스트링 보완. 피아노/신디/브라스/어쿠스틱/일렉/베이스/드럼 제외 조건.
8. 악기 8개+나머지=반주 합계, 프레임/스테레오/유한값 검사 및 무음 표시 판정 후 저장.

사용자가 선택한 기본 브라스 출력을 적용하므로 별도의 CLAPSep 브라스 보완은 적용하지 않는다. 브라스 부재 오렌지 구간에서 CLAPSep가 큰 출력을 내던 후보는 채택하지 않았다. 텍스트 제외 조건은 완전 차단 보장이 아니다.

## 진행률

| 작업 | 전체 진행률 범위 |
|---|---|
| 변환 | 0–5% |
| 보컬/반주 | 5–32% |
| 피아노/베이스/드럼 | 32–52% |
| Mega5 악기 | 52–66% |
| 리드/코러스 | 66–84% |
| 나머지 생성 | 84–85% |
| 신디 보완 | 85–91% |
| 스트링 보완 | 91–97% |
| 검증/저장 | 97–100% |

각 추론 범위는 실제 완료 청크/전체 청크 비율로 갱신한다. 보완 추론도 progress.json을 원자적으로 기록하고 부모 프로세스가 읽어 진행률과 구간 수를 갱신한다. 모델 로딩에는 추론 완료를 가장한 시간 기반 증가를 사용하지 않는다. 진행률은 단계별 작업 비중이며 경과 시간이나 정확한 남은 시간 예측은 아니다. 100%는 검증과 저장 후 SUCCEEDED에서만 표시한다.

## 구성과 검증

- 내부 업로드 preset `final_10`은 기존 호출 호환을 위해 유지한다. 새 결과 버전 `instrumental-with-brass-v5`, layout `flat_v4`, 잔여 `remaining-v4.wav`.
- 모델은 `bs_roformer_mega5`, 추론 preset은 `instrument_mega5`. 생성: `scripts/prepare-final-instruments.py --brass`. 모델 및 코드·설정 해시 검증, strict load, 공유 GPU 잠금과 OOM fallback 유지.
- 프런트 표시/볼륨/solo/mute/원시 WAV/ZIP/선명도에 brass를 연결했다. 기존 완료 분석은 이전 모델 결과로 보존한다. 새 구성은 재분석 또는 새 업로드에 적용한다.
- 관련 Python 테스트 62개와 프런트 테스트 7개 통과. 별도 20초 전체 분석은 모델 입출력과 최종 합계·파일 계약을 검증한다. 실제 브라스 품질의 근거는 사용자의 분홍신 청취 승인이다.

## 실험용 음량 기반 누출 억제 적용

사용자 승인으로 새 분석에 energy-gentle-v1을 적용한다. 브라스·스트링·신디의 보완 전 RAW와 반주의 100ms RMS를 비교하고 ON -38dB/OFF -44dB, 50ms attack/300ms release로 최종 출력을 감쇠한다. 보완 추출의 실행 여부는 변경하지 않는다. 감쇠분은 나머지로 반환하고 반주 합계를 검증한다. 이전 파일과 record-before-leakage-rule-v1.json을 보존한다. 기존 완료 결과는 자동 변경하지 않는다. 비교에서 내 이름 맑음의 만족한 스트링·신디까지 감쇠된 한계가 있어 악기 존재 판정으로 취급하지 않는다. 서버 재시작 후 새 분석부터 적용된다.

### 신디 보완 결과 유지 v2

미라클 제너레이션 pre_gate_synth 청취 승인으로 새 분석의 신디는 보완 후 출력을 그대로 유지한다. energy-gentle-synth-preserved-v2의 음량 억제 대상은 브라스·스트링이며, 신디에 적용하지 않는다. 현재 미라클 완료 결과도 보완 후 신디로 복원하고 나머지를 재계산했다. 스트링·브라스 출력은 변경 전과 샘플 단위로 동일함을 검증했다. MyGO처럼 신디가 없는 곡의 보완 누출은 이 변경만으로 해결되지 않는다. 기존 v1 파일과 분석 기록은 보존한다.
