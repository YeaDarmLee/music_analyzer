# 선택한 신디사이저 보완 방식의 전체곡 검증

사용자가 미라클 14–24초의 `기타·드럼·보컬 제외 · 지속 화음 · 나머지 입력`을 선택했다. 같은 조건을 미라클과 오렌지 전체 잔여 신호에 적용해 재현성을 확인한다.

- 긍정 조건: `electronic synthesizer playing sustained chords`
- 제외 조건: `electric guitar, acoustic guitar strumming, drums, lead singing and backing vocals`
- 기존 신디에 추출분을 더하고 기존 나머지에서 동일 신호를 뺀다. 다른 8개 트랙은 변경하지 않는다.
- CLAPSep의 핀된 모델·코드 해시를 검증하고 로컬 캐시만 사용한다. 양 채널 독립 추론, 32kHz 처리 후 44.1kHz 복원, 10초 청크·50% 중첩이다.
- 모델은 한 번 로드해 두 곡을 처리하며, 사용자가 선택한 조건 하나만 실행한다. 기존 30초 제한은 일반 짧은 실험에 유지하고 `full_song_study=true`인 실험만 최대 600초를 허용한다.

`scripts/study-synth-full.py prepare`는 오렌지를 별도의 `data/part-studies/synth-full-validation/orange-library`에서 최종 10트랙으로 분석한다. 모델 파일은 기존 체크포인트의 하드링크를 읽는다. 미라클은 기존 완료 분석을 읽는다. `infer`로 보완 추출, `build`로 원시 출력·청취 화면·검증 파일을 만든다.

결과 경로: `data/part-studies/synth-full-validation/comparison.html`, `verification.json`, 곡별 `manifest.json`.

원곡/기존/보완 출력은 곡별 동일한 재생 게인을 사용한다. 전체 재생과 짧은 비교 구간을 함께 제공한다. 합계 재구성 검증은 분리 정확도가 아니며 목표 신디 유지, 기타·드럼·보컬 유입, 신디가 없는 구간의 오검출을 청취로 확인해야 한다. 지속 화음 조건은 짧은 신디 멜로디를 놓칠 수 있다. 이 검증은 회원 DB·서비스 기본값·기존 회원 결과를 변경하지 않는다.

## 실행 결과

- 미라클: 10,626,048 프레임, 보완 추출·복원·출력 기록 7.63초, 10트랙 합계 최대 오차 2.92e-8.
- 오렌지: 10,353,664 프레임, 보완 추출·복원·출력 기록 8.18초, 10트랙 합계 최대 오차 5.30e-8.
- 모델 GPU 최대 할당 메모리 약 1.27GiB. 모델 생성·체크포인트 로딩 및 기존 10트랙 추출 시간은 위 보완 처리 시간에서 제외한다.
- 유한값, 샘플레이트, 스테레오, 프레임 일치, 두 트랙 합계 및 10트랙 합계 검증 통과. 관련 기존 실험 테스트 4개 통과.
- 전체 청취 품질은 아직 확인 전이며 서비스에 승격하지 않았다.
