# Orange 연주 파트 분리 비교

2026-10-06, 이예닮 계정의 SPYAIR — Orange를 대상으로 실행했습니다. 기본 분석 모델은 변경하지 않았습니다.

## 청취 방법

로그인 후 라이브러리의 `Orange · 기타 비교` 및 `Orange · other·신스 비교`를 엽니다. 구간은 0:40–1:00, 1:40–2:00입니다. 모든 트랙은 처음에 음소거되어 있습니다. S 버튼으로 하나씩 선택한 뒤 재생하여 같은 시간대의 기존 결과와 후보 A/B를 비교합니다. 여러 S 버튼을 켜면 함께 재생됩니다.

REF는 분리 전 기타 또는 other 부모 트랙입니다. 기존 1/2는 원래 분석 결과이며, baseline은 동일 구간을 기존 프롬프트로 다시 추론한 결과입니다. 후보 A/B는 리드/리듬 기타 또는 패드/반복 음형을 각각 독립 추론합니다. 차이 신호는 입력에서 A+B를 뺀 값으로, 별도 악기를 뜻하지 않습니다. other에는 신스 외의 소리가 포함될 수 있습니다.

## 실행 결과와 한계

고정된 CLAPSep 가중치로 실제 GPU 추론 20회를 완료했습니다. 모든 출력은 44.1kHz 스테레오이며 입력과 길이를 맞췄습니다. 파트별 효과음 꼬리를 유지한 합성 패드+아르페지오와, 두 번째 파트가 없는 패드+효과음 대조군을 함께 실행했습니다.

| 합성 정답 평가 | SI-SDR (dB) |
| --- | ---: |
| 기존 프롬프트 패드 | 12.64 |
| 독립 텍스트 후보 패드 | 11.93 |
| 참고 오디오+텍스트 패드 | 13.79 |
| 독립 텍스트 후보 아르페지오 | 5.55 |
| 참고 오디오+텍스트 아르페지오 | 4.78 |

참고 오디오는 패드에서 개선됐지만 아르페지오에서는 악화됐습니다. 두 번째 파트가 없는 대조군에서도 B 출력 에너지가 입력 에너지의 47.85%였습니다. 따라서 두 출력이 존재한다는 사실만으로 서로 다른 연주 파트라고 판단할 수 없습니다. 실제 Orange 후보 간 상관도도 0.57–0.77로 겹침 가능성이 남습니다. 상관도는 분리 정확도가 아니며 실제 곡의 정답 트랙은 없습니다.

현재 결과는 청취 평가용 후보이며 품질 개선 검증을 통과한 제품 기능이 아닙니다. 좌우 채널을 각각 추론하여 스테레오 정체성이 변할 가능성도 있습니다. 다음 단계는 곡에서 각 연주가 잘 드러나는 참고 구간을 선정해 참고 오디오 기반 추출을 비교하고, 단일 파트 대조군에서 잘못된 두 번째 파트를 억제하는 것입니다.

SAM Audio는 체크포인트 접근 동의와 별도 환경이 필요하여 실행하지 않았습니다. 접근 승인 이후 시간 구간을 지정하는 방식과 비교할 수 있습니다.
