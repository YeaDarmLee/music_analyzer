# 미라클 제너레이션 신디사이저 보완 실험

회원 라이브러리와 서비스 기본값을 수정하지 않고 14–24초를 비교했다.
실행 스크립트: `scripts/study-synth-recovery.py` (`prepare`, `mega`, `clap`, `build`).
비교 화면: `data/part-studies/miracle-synth-check/comparison.html`.

## 확인된 사실

- 기존 신디 RMS 0.000231, 나머지 RMS 0.021638. 이 값은 추출 정확도가 아니다.
- 공식 Mega53의 25번 keys와 38번 synth 헤드를 원곡·나머지 입력에서 비교했다. 체크포인트 SHA 검증, strict load, GPU 공유 잠금, 10초 청크, 50% 중첩, AMP를 사용했다.
- 원곡 synth RMS 0.000395, 나머지 입력 synth RMS 0.010804. 같은 모델도 입력의 간섭을 줄이면 출력이 달라진다. 실제 신디 연주인지와 다른 악기의 유입은 청취 확인이 필요하다.
- 원곡 keys RMS 0.060406으로, 현재 피아노 RMS 0.061377과 비슷하다. 이 사실만으로 동일 악기라고 판단할 수 없고 피아노 중복 가능성을 확인해야 한다.
- CLAPSep 세 가지 텍스트 조건을 두 입력에서 실제 추론했다. 로컬 캐시만 사용하며 원시 스테레오 출력을 보존했다. 채널별 독립 추론이므로 스테레오 보존을 보장하지 않는다.
- 오렌지 9–19초의 기존 신디와 keys/synth 후보를 비교 화면에 함께 제공한다. 짧은 구간은 전체 곡과 경계 문맥이 달라 출력이 완전히 같지는 않다. 나머지 재추출 방식의 오렌지 역검증은 아직 하지 않았다.

## 우선 청취 후보

`보완 후보 신디사이저 = 현재 신디 + Mega53(현재 나머지)의 synth`

`보완 후보 나머지 = 현재 나머지 - 위 재추출분`

두 트랙 합계 보존 오차는 최대 5.21e-9였다. 이는 산술 재구성 검증이며 악기 분리 품질 검증은 아니다. 후보 간 합산은 하지 않는다.

다음 단계는 미라클 후보의 신디 연주 복구 및 다른 악기 유입 청취 확인이다. 통과하면 오렌지의 전체 10트랙 잔여 신호에서도 같은 재추출을 검증하고, 성공한 경우에만 최종 분석 파이프라인에 반영한다. 무조건 반복하거나 나머지 전체를 신디로 재명명하지 않는다.

## 다른 악기 유입 억제 후보

사용자가 재추출 후보의 다른 소리 유입을 지적해 약한/강한 억제 후보를 추가했다. 기존 8개 악기·보컬 출력과 재추출 신호 사이의 국소 STFT coherence를 계산하고, 겹치는 성분을 부드럽게 감쇠한다. 양 채널에 동일 마스크를 적용한다. 2048 프레임 FFT, 512 hop, 시간 9프레임 평균, 감쇠 강도 0.5/0.85이다. 새 학습 모델이나 악기 분류기는 아니다.

신디와 다른 악기가 같은 음을 연주하면 신디도 줄어들 수 있으며, 기존 출력에 없는 유입은 잡지 못할 수 있다. 차단 성공은 아직 청취로 검증되지 않았다. 무감쇠 STFT 왕복 최대 오차 1.49e-8, 보완 신디+나머지 합계 보존 검증 통과. `suppress` 후 `build`로 재생성한다. 서비스 기본값은 변경하지 않았다.

## 악기를 명시한 제외 조건

사용자가 일렉기타·통기타·드럼·보컬 유입을 특정해 CLAPSep 음성 조건을 추가했다. 음성 제외 문구는 `electric guitar, acoustic guitar strumming, drums, lead singing and backing vocals`이다. 긍정 문구는 일반 신디/밝은 멜로디/지속 화음 세 가지이며 원곡과 나머지를 각각 입력한다. `exclude` 실행 후 `build`로 비교 화면을 갱신한다. 이전 실험은 덮어쓰지 않는다.

제외 문구는 모델의 조건 입력이며 해당 악기를 반드시 차단하는 필터가 아니다. 제거율이나 분리 성공을 주장하지 않는다. 나머지 입력 후보에 대해서만 재추출분을 기존 신디에 더하고 잔여에서 빼는 산술 재구성 검증을 수행한다. 원곡 입력 후보는 기존 트랙과 중복될 수 있어 직접 합산하지 않는다. 청취로 목표 연주 보존과 유입 감소를 확인하기 전 기본 모델을 변경하지 않는다.
