# 브라스 추가 계획

2026-10-07. 계획만 작성하며 서비스 모델과 출력은 변경하지 않는다.

## 후보와 선택

1. 공식 Mega53 `brass`(index 8)를 현재 Mega4의 acoustic-guitar/electric-guitar/synth/bowed_strings와 함께 선택한 Mega5를 우선 실험한다. 기존 연구 모델의 broad strings(index 37)를 다시 사용하지 않는다. 공식 checkpoint와 설정 순서를 검증하고 strict load 및 선택 헤드 동등성 확인을 수행한다. 현재 encoder를 공유하는 방식이라 별도 브라스 전체 모델을 추가하는 것보다 계산을 재사용할 수 있으나 실제 시간·메모리는 측정한다.
2. 기존 설치된 CLAPSep는 브라스 보완 후보로 비교한다. 범용 조건부 추출 모델이며 브라스 전용 학습 모델이라고 부르지 않는다. `brass instruments playing, trumpets, trombones and French horns`를 출발점으로 지속음과 짧은 brass hits를 각각 비교한다. 제외 조건은 피아노·신디·스트링·어쿠스틱/일렉기타·베이스·드럼이다. 텍스트 제외는 완전 차단을 보장하지 않는다.
3. AudioSep는 텍스트 기반 대체 후보, SAM Audio는 텍스트/구간 지정 대체 후보이다. 기존 후보가 실패할 때만 설치 상태·가중치 사용 조건·GPU 실측을 확인해 비교한다. 이번 공식 자료 조사에서 바로 채택할 검증된 별도 브라스 단독 체크포인트는 확보하지 못했다.

## 우선 흐름

변환 → 보컬/반주 → 반주에서 악기 8개(브라스 포함) → 보컬/코러스 → 반주에서 악기 8개를 빼 나머지 생성 → 신디 보완 → 스트링 보완 → 브라스 보완 → 검증/저장.

브라스 보완분은 브라스에 더하고 같은 신호를 나머지에서 뺀다. 악기 8개+나머지=분리된 반주를 유지한다. 다른 보완 단계가 브라스를 먼저 가져갈 수 있으므로 신디·스트링 제외 조건에 brass를 넣는 후보도 대조한다. 브라스 보완을 먼저 하는 대조 실험은 소리가 다른 트랙으로 옮겨지는지 평가하기 위한 것으로 기본 순서를 미리 확정하지 않는다.

목표는 실제 금관악기다. 신디 브라스 패치는 기본적으로 신디 트랙에 둔다. 색소폰·목관은 브라스에 자동 합산하지 않는다. trumpets/trombones/french-horn/brass 개별 출력은 중첩될 수 있어 단순 합산하지 않는다.

## 검증과 적용

- 실제 브라스가 명확한 15–30초, 브라스 없는 기타 중심 구간, 신디 브라스와 실제 브라스를 혼동하기 쉬운 구간을 비교한다. 오렌지는 사용자 설명상 브라스가 없어 음성 대조군으로 사용한다.
- 비교 후보: Mega53 brass 단독 / CLAPSep 단독 / Mega53+잔여 보완. 원본·기존/보완 브라스·신디·스트링·나머지를 같은 재생 게인으로 제공한다.
- 청취에서는 목표 연주, 기타·드럼·보컬 유입, 신디·스트링 중복과 손실, 브라스 없는 구간 오검출을 확인한다. 정답 stem이 없는 곡에서 에너지·상관·합계 보존을 분리 정확도로 보고하지 않는다.
- 시간, 모델 로딩, GPU 최대 할당, 스테레오와 프레임 수, 무음 및 합계 검증을 기록한다. 현재 무음 숨김은 악기 부재 판정이 아니며 누출 출력이 있으면 숨김만으로 해결할 수 없다.
- 통과하면 11트랙으로 표시·개별 WAV·ZIP·재생·선명도·진행 단계·캐시를 갱신한다. 제안 표시 순서: 보컬, 코러스, 피아노, 신디사이저, 스트링, 브라스, 어쿠스틱기타, 일렉기타, 베이스, 드럼, 나머지. 기존 결과는 보존한다.
