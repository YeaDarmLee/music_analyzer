# 12트랙 v9: 무조건 잔여음 보완 제거

실험 브랜치의 신규 `final_11` 분석은 `staged-guitar-residual-v9`와
`recovery_policy=base-estimates-only-v1`을 기록한다. 기본 모델의 신디·스트링·브라스
추정치를 그대로 사용하고 잔여음을 `other`에 보존한다. 소리 크기로 악기를 삭제하지 않는다.
기존 결과 파일과 명시적으로 실행하는 보완 도구는 보존된다.

9개 정답 데이터에서 무조건 CLAPSep 보완이 없는 악기 유입과 작은 악기 오류를
증가시켰다. 조용한 신디 SDR은 -7.73→-4.01 dB, 조용한 브라스는 -4.96→-0.66 dB로
개선된다. 악기가 없는 대조군은 신디 유입이 5.17 dB, 브라스 유입이 10.85 dB 줄어든다.
단, 일반 신디의 SDR은 0.63→0.01 dB로 낮아지고 여전히 대부분을 놓친다.
따라서 이 변경은 누출 억제이며 신디/기타 검출 누락까지 해결한 것은 아니다.
과거 미라클에서 사용자가 선택한 보완의 이점도 자동 분석에서는 제공하지 않는다.
해당 수동 보완 기능 자체는 유지되지만 그 곡의 v9 전체 품질은 새로 검증하지 않았다.

검증은 이미 실제 GPU 모델로 분석한 9개 사례의 원시 출력으로 변경된 최종 조립 함수를
실행했다. 모델 추론은 재실행하지 않았다. 모든 사례에서 12트랙, 반주 합계 복원,
기존 보완 제거 후보와 최대 오차 2e-6 미만을 확인했다.
`scripts/verify-ground-truth-v9.py`가 재현 스크립트이며
`TWELVE_TRACK_V9_VERIFICATION.json`에 사례별 결과가 있다.
새 청취 화면은 각 사례의 `v9/comparison.html`에 저장한다.

실제 녹음의 신디·브라스 존재/부재 사례를 추가 검증하기 전에는 main에 병합하지 않는다.
합성 사례는 16kHz mono VST라 실제 녹음 일반화와 학습 데이터 중복 여부를 보장하지 않는다.
